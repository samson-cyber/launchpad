## 3. The Round W ruling and why

On 2026-10-07 Samson ruled option (c): fresh installs rotate wallpaper by default. CC stopped
because:

1. `privacy-policy.html` scopes the Unsplash fetch to a wallpaper the user *chooses*; a default-on
   fetch on first paint is not covered by the published wording.
2. `[1.0.19 D11]` (at `DEFAULT_BG`, newtab.js:140) says the default is deliberately not a gallery
   image: first paint must not depend on a third-party fetch, and the image path adds `bg-image`
   with no luminance class.
3. `[1.11.3]` (at `GALLERY_URLS`) makes off-by-default the premise that made the Unsplash trade
   acceptable.

CC also measured first paint 604 ms cold / 218 / 247 warm, and offline falling to `#2a2a2a` with
`bg-image` and no class. Its brightness census of the twelve gallery images: ten are dark
(mean L .049 to .109, 4.5% to 18.0% of frame above L=0.18); two are bright, `safe_tropical_beach`
[2] (L .199, 59.2%) and `safe_northern_lights` [11] (L .137, 36.3%). The beach is the ink
sweep's own photo-light ground.

**Ruling 2026-11-08 (Samson): route A1.** One clean nature photograph, bundled inside the
extension, becomes the fresh-install default. Rotation stays off by default. No network fetch on
first paint, so the privacy paragraph stands, `[1.11.3]`'s premise holds, and `D11`'s first reason
is removed by bundling. `D11`'s second reason (no luminance class on a photo) is accepted on a dark
image and measured in the round. This reopens `[1.10.0]` decision 2 for this one default,
deliberately; existing profiles are untouched.

**Pool narrowing: yes**, as its own first commit (Claude Chat's lean, Samson delegated). Automatic
rotation draws from the ten dark images; the picker keeps all twelve. It changes an existing
rotation user's picture of the day once, and removes two unreadable days a month.

## 5. How this project works (short form; `CLAUDE.md` and `ASANA.md` are canonical)

- Claude Chat plans, writes PLAN/REVIEW on Asana, authors CC prompts. CC implements in a worktree
  on a branch, verifies in a real browser, posts IMPLEMENTATION ending with HUMAN CHECKS REMAINING,
  merges `--ff-only`. Docs-only commits go direct to master.
- Premise audit before any edit; STOP and post a STOPPED comment on any mismatch. Never build
  against a wrong premise.
- `build.sh` refuses to build with uncommitted changes; never bypass. Every round ends with
  `build.sh` exit 0, all gates, artifact bytes + sha256 reported, zip deleted (no candidate zip
  between releases). Artifact sha is checkout-dependent; the upload artifact is built in the MAIN
  checkout.
- M3 (every edit through a writer, no shell parser), M7 (CRLF preserved), M9 (no NULs), I13
  (contrast measured from composited screen pixels, never declared colours).
- Asana: `get_task` with `comment_limit 50`; `add_comment` with `text` only; close = `completed:true`
  + `add_projects` to Completed (1214252324886230) in one call; `search_tasks` is premium-blocked,
  use `get_tasks` by section. Sections: In Progress 1214252324886228, Needs Review
  1214252324886229, Completed 1214252324886230, Bugs 1214252324886231, Fixed Bugs 1214252324886232,
  Backlog 1214252324886233. Kickoff task 1214275087201909.
- Ruling 56: if an Asana post fails, say so in the terminal output and paste the comment text.
- `git log --grep` with several patterns is OR-ed; check each task id alone.
- Paths: `C:\Dev\Git\launchpad` (master), `C:\Dev\Git\launchpad-website` (main). Never OneDrive.
  Extension stylesheet is `newtab.css`; `styles.css` is the website's.
- No em dashes in product copy or docs. Preview-is-the-promise. One hero per surface, one accent
  (orange `--action`), glass is the material.
- Samson is terse ("cc done", "go", "your lean"). He vetoes by naming what is wrong. Give him
  options with a lean; never wrap a session unprompted.
